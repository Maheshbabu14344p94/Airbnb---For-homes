AI PROMPT LOG — PLAYPOWER LABS AIRBNB CLONE
================================================

Project: Premium 3D Airbnb Listing Clone
Stack: React, TypeScript, Vite, Tailwind CSS

PROMPT 01 — REQUIREMENTS ANALYSIS
---------------------------------
Analyze the attached PlayPower Labs Airbnb Clone assignment carefully. Extract the functional requirements, required screens, interaction requirements, accessibility expectations, technical constraints, and submission deliverables. Create a concise implementation checklist and identify the highest-priority areas for visual and behavioral fidelity.

PROMPT 02 — REFERENCE ANALYSIS
------------------------------
Study the provided Airbnb reference page and screenshots conceptually. Break the experience into reusable UI sections: navigation, property gallery, listing information, booking card, amenities, reviews, location, host section, Photo Tour, and Lightbox. Identify important spacing, hierarchy, typography, rounded surfaces, shadows, controls, and interaction patterns. Build an original implementation without copying the reference source code.

PROMPT 03 — PREMIUM VISUAL DIRECTION
------------------------------------
Implement the assignment as a premium, original Airbnb-inspired experience. Keep the required listing structure and functionality, but elevate the visual design with cinematic property photography, layered depth, floating cards, subtle glassmorphism, soft shadows, perspective transforms, smooth transitions, and a polished modern aesthetic.

PROMPT 04 — PROJECT ARCHITECTURE
--------------------------------
Create a clean React + TypeScript + Vite project structure. Separate reusable UI components from data and interaction logic. Keep the architecture simple and focused on the assignment requirements. Avoid unnecessary backend infrastructure because the assignment allows a frontend-focused implementation.

PROMPT 05 — PREMIUM 3D LANDING EXPERIENCE
-----------------------------------------
Create a premium landing experience for the Airbnb property. Present a beautiful modern home using high-quality property imagery. Add 3D perspective, floating information cards, depth through shadows and transforms, and an interactive home presentation. Allow horizontal dragging to create a 360-degree-style viewing experience and include a clear CTA that transitions into the main Airbnb listing.

PROMPT 06 — 3D CARD INTERACTION
-------------------------------
Add polished floating-card interactions throughout the experience. Cards should respond naturally to mouse movement with subtle rotation and translate effects. Support click-and-drag interaction where appropriate, use a hand/grab cursor during dragging, and return smoothly to the resting position after release. Keep the movement restrained and premium.

PROMPT 07 — PROPERTY GALLERY
-----------------------------
Build the main property gallery using high-quality home and interior imagery. Use an editorial layout with large rounded image surfaces and supporting images. Add hover scale, perspective depth, subtle shadows, and accessible controls. Clicking a gallery image should open the appropriate photo-viewing experience.

PROMPT 08 — PHOTO TOUR
----------------------
Implement the required full-screen Photo Tour. Open it from the “Show all photos” control and gallery images where appropriate. Present the property images in a polished gallery layout with smooth transitions, clear controls, image counters, and a close action.

PROMPT 09 — LIGHTBOX
--------------------
Implement a production-quality single-image Lightbox. It must support previous and next image controls, keyboard navigation with Left Arrow and Right Arrow, and closing with Escape. Add smooth image transitions, visible focus states, and accessible labels.

PROMPT 10 — LISTING PAGE
------------------------
Build the complete Airbnb-style property listing page after the landing experience. Include navigation, property title and metadata, premium photo gallery, rating/review information, description, amenities, location, host information, house rules, cancellation information, and floating reservation card. Use consistent spacing and premium depth effects.

PROMPT 11 — INTERACTIVE BOOKING CARD
------------------------------------
Create the reservation card as an elevated floating panel. Include date selection, guest selection, pricing summary, and a primary reservation CTA. Add polished hover and focus states with subtle lift animation. Keep booking behavior simulated because this is a frontend assignment.

PROMPT 12 — AMENITIES AND CONTENT MODALS
-----------------------------------------
Add an amenities section with a “Show all amenities” interaction. Open the complete amenities list in an accessible modal with a clear close control. Add expandable property description content where useful.

PROMPT 13 — REVIEWS AND LOCATION
-------------------------------
Implement the reviews section with overall rating, category breakdown, and review cards. Add a polished location section with a map-style presentation. Keep the data structured locally so it can later be replaced by an API.

PROMPT 14 — MOTION AND MICRO-INTERACTIONS
-----------------------------------------
Add motion carefully across the application: entrance transitions, hover elevation, image scaling, card perspective, modal transitions, and subtle parallax. Avoid excessive animation and prioritize smooth transform-based effects.

PROMPT 15 — ACCESSIBILITY REVIEW
--------------------------------
Audit the application for keyboard accessibility and semantic HTML. Verify interactive elements, visible focus states, accessible labels, modal behavior, Escape handling, and Left/Right Lightbox navigation. Add reduced-motion considerations where appropriate.

PROMPT 16 — CODE QUALITY REVIEW
-------------------------------
Review the entire React + TypeScript implementation for maintainability. Look for duplicated JSX, weak typing, unnecessary state, unclear component responsibilities, unused imports, inconsistent naming, and avoidable re-renders. Refactor only where it improves clarity or reliability without changing intended behavior.

PROMPT 17 — VISUAL POLISH PASS
------------------------------
Perform a final premium visual polish pass. Inspect spacing, border radii, shadows, image cropping, typography hierarchy, button states, floating-card positioning, depth effects, and transitions. Make the interface feel cohesive and production-quality.

PROMPT 18 — REQUIREMENTS VALIDATION
------------------------------------
Validate the implementation against the original assignment checklist. Confirm Listing Page, Photo Tour, Lightbox, keyboard navigation, accessibility, desktop-only scope, and required submission artifacts are present. Identify anything missing before packaging.

PROMPT 19 — ARCHITECTURE DIAGRAM
--------------------------------
Create a high-level production-scale architecture diagram for a vacation-rental marketplace. Show frontend, CDN, backend/API, authentication, database, object storage for property images, search/indexing, caching, queues/background processing, observability, and deployment infrastructure.

PROMPT 20 — FINAL SUBMISSION REVIEW
-----------------------------------
Perform a final submission review. Check the project structure, README, architecture diagram, AI prompt log, agent/skill configuration, source files, package configuration, and required interactions. Ensure there are no obvious unused files or missing deliverables. Prepare the project as a clean submission ZIP.

FINAL VALIDATION PROMPT
-----------------------
Act as a senior frontend engineer reviewing this take-home assignment before submission. Validate visual fidelity, behavioral parity, accessibility, component quality, 3D interactions, Photo Tour, Lightbox, and documentation. Report only actionable issues and provide the smallest safe fixes needed.
