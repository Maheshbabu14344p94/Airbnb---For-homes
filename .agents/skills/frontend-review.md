# Frontend Review Skill

## Goal
Audit the clone before submission for visual fidelity, behavior, accessibility, and TypeScript quality.

## Checklist
- Compare desktop spacing, type scale, borders, radii and image crop against the supplied reference screenshot.
- Verify hero image, Show all photos, photo-tour categories and lightbox transitions.
- Verify ArrowLeft, ArrowRight and Escape behavior in the lightbox.
- Verify dialog focus visibility and Escape close behavior.
- Verify no horizontal layout overflow at the target desktop viewport.
- Verify `npm run build` completes with TypeScript strict mode enabled.
- Prefer semantic HTML and buttons for actions.
- Respect `prefers-reduced-motion`.
